# Базовые понятия Git

Git хранит историю проекта как последовательность снимков. Коммит фиксирует подготовленное состояние файлов, ветка указывает на один из коммитов, а `HEAD` показывает текущую позицию пользователя в истории.

Каталог `.git` содержит объектную базу, ссылки на ветки и теги, индекс, настройки репозитория и журнал перемещений ссылок. Удаление этого каталога превращает рабочую папку в обычный набор файлов без локальной истории Git.
