# Лабораторные работы по Git

Репозиторий используется для практики базовых операций Git и работы с тематическими ветками.

## Содержимое

- `readme.txt` — небольшой файл, история которого использовалась для просмотра версий;
- `main/test.png` — тестовое изображение из первоначального задания;
- `notes/` — конспекты по командам и структуре репозитория;
- `examples/` — короткие памятки для проверки рабочего процесса.

## Основной рабочий цикл

1. Проверить состояние командой `git status`.
2. Добавить нужные изменения в индекс.
3. Создать атомарный коммит с понятным сообщением.
4. Отправить изменения в GitHub.
